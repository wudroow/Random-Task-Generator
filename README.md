# Random Task Generator

**Автор:** Выдрина Виктория Игоревна

**Дата:** 4 мая 2026 г.

## Описание программы

Random Task Generator — это приложение с графическим интерфейсом для генерации случайных задач. Программа помогает выбрать задачу из категорий "Учёба", "Спорт" или "Работа". Пользователь может добавлять свои задачи, фильтровать по типу и просматривать историю всех сгенерированных задач.

## Требования для запуска

- Python 3.10 или выше
- Операционная система: Windows, macOS или Linux

Дополнительные библиотеки не требуются, используются только стандартные модули Python: tkinter, random, json, os, datetime.

## Как пользоваться программой

**Добавление задачи:** введите название, выберите тип (Учёба/Спорт/Работа), нажмите "Добавить задачу".

**Генерация задачи:** выберите фильтр, нажмите "Сгенерировать задачу".

**Просмотр истории:** все задачи отображаются в таблице справа.

**Очистка истории:** нажмите "Очистить историю" и подтвердите.

## Пример работы

Добавление: пользователь вводит "Выучить теорему Пифагора", выбирает "Учёба", нажимает "Добавить задачу" → программа сообщает "Задача добавлена".

Генерация: выбран фильтр "Спорт", нажата кнопка "Сгенерировать задачу" → результат "Сделать 20 приседаний" добавляется в историю.

Проверка ввода: поле пустое → программа выдаёт ошибку "Задача не может быть пустой".

## Возможные проблемы

- Ошибка "Нет модуля tkinter" → установите python-tk (Linux) или переустановите Python
- Программа не запускается → проверьте, что файл называется main.py
- История не сохраняется → проверьте права на запись в папке
